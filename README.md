# BAM Chemistry Lab

Interactive periodic table — 118 elements with details, search, filters, and multi-language support (English + Urdu).

## Features

- **118 elements** — complete periodic table with real data
- **Multi-language** — English + Urdu with RTL support
- **Search** — by name, symbol, or atomic number
- **Filters** — Metals, Non-metals, Noble gases
- **Lanthanides & Actinides** — separate rows with jump buttons
- **Element details** — modal popup with full info
- **Dark theme** — emerald + gold accents
- **Mobile-friendly** — responsive grid

## Tech Stack

- Pure HTML / CSS / JavaScript (no frameworks, no build step)
- Deployed on Cloudflare Pages

## Structure

- `index.html` — Main page
- `style.css` — Styles
- `app-v4.js` — Rendering logic
- `js/i18n.js` — Language switcher
- `data/elements.json` — 118 elements data
- `data/i18n/en.json` — English translations
- `data/i18n/ur.json` — Urdu translations
